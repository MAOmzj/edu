小学数学计算与思维专题百科

本资料是《数学基础》和《数学应用题类型》的配套专题，专注计算能力训练、速算技巧、数学思维方法和解题策略。计算是数学的基本功，思维是数学的灵魂——计算要又快又准，思维要活而有序。

============================================================
第一篇：口算与速算技巧
============================================================

一、加法速算

【凑整法】
把接近整十整百的数先凑成整数再加减。
如 98+37 = (100-2)+37 = 100+37-2 = 135
如 197+256 = (200-3)+256 = 200+256-3 = 453

【分组凑整】
多个数相加时，先把能凑成整十整百的数配对。
如 23+45+77+55 = (23+77)+(45+55) = 100+100 = 200
如 36+87+64+13 = (36+64)+(87+13) = 100+100 = 200

【连续进位加法】
从个位加起，满十向前一位进1。口算时记住进位。
如 467+358：个位 7+8=15 写5进1，十位 6+5+1=12 写2进1，百位 4+3+1=8，结果 825。

二、减法速算

【借位减法技巧】
如 503-267：个位不够减，向十位借，十位是0，向百位借，百位变4，十位变10再借1给个位变10，13-7=6，9-6=3，4-2=2，结果 236。

【减去接近整数的数】
如 432-198 = 432-(200-2) = 432-200+2 = 234
如 567-299 = 567-(300-1) = 567-300+1 = 268

【连减的简便运算】
a-b-c = a-(b+c)。先把要减的数加起来再减。
如 356-78-22 = 356-(78+22) = 356-100 = 256

三、乘法速算

【特殊数乘法】
25×4=100，25×8=200，125×8=1000，125×4=500
看到25找4搭配，看到125找8搭配。
如 25×36 = 25×4×9 = 100×9 = 900
如 125×24 = 125×8×3 = 1000×3 = 3000

【乘法分配律巧算】
如 99×46 = (100-1)×46 = 100×46-1×46 = 4600-46 = 4554
如 101×58 = (100+1)×58 = 100×58+1×58 = 5800+58 = 5858
如 98×75 = (100-2)×75 = 7500-150 = 7350

【提取公因数】
a×c+b×c = (a+b)×c
如 37×56+37×44 = 37×(56+44) = 37×100 = 3700
如 85×23+15×23 = (85+15)×23 = 100×23 = 2300

四、除法速算

【商不变性质】
被除数和除数同时乘或除以相同的数（0除外），商不变。
如 600÷25 = (600×4)÷(25×4) = 2400÷100 = 24
如 800÷50 = (800×2)÷(50×2) = 1600÷100 = 16

【利用特殊数关系】
如 4800÷12 = 4800÷(4×3) = 4800÷4÷3 = 1200÷3 = 400
如 3600÷25 = 3600÷(100÷4) = 3600×4÷100 = 144

第二篇：小数与分数计算专项
============================================================

五、小数计算要点

【小数点对齐原则】
加减法：小数点对齐（即相同数位对齐），从最低位算起。
如 3.75+2.8 = 3.75+2.80 = 6.55（2.8要补0对齐）

【小数乘法的步骤】
1. 先按整数乘法算出积。
2. 数两个因数一共有几位小数。
3. 从积的右边起数出相同位数，点上小数点。
4. 位数不够用0补足。
如 0.25×0.4：先算 25×4=100，两个因数一共3位小数，从右数3位得 0.100，化简为 0.1。

【小数除法的转化】
除数是整数：直接除，商的小数点与被除数对齐。
除数是小数：先把除数和被除数同时扩大相同倍数，使除数变成整数再除。
如 3.6÷0.25 = 360÷25 = 14.4（同时扩大100倍）

六、分数计算要点

【约分和通分的区别】
约分：分子分母同时除以公因数，化简分数。如 12/18 = 2/3（同除以6）。
通分：异分母分数化成分母相同的分数。如 1/3 和 1/4 通分为 4/12 和 3/12。

【分数加减法】
同分母：分母不变，分子相加减。如 3/7+2/7 = 5/7。
异分母：先通分再计算。如 1/3+1/4 = 4/12+3/12 = 7/12。

【分数乘除法】
乘法：分子乘分子，分母乘分母，能约分先约分。
如 2/3×3/4 = (2×3)/(3×4) = 6/12 = 1/2（先约分：2和4约得1和2，3和3约得1和1，=1/2）
除法：除以一个数等于乘这个数的倒数。
如 2/3÷4/5 = 2/3×5/4 = 10/12 = 5/6

【带分数计算】
先化成假分数再计算，最后结果能化成带分数的要化成带分数。
如 1又1/2 + 2又2/3 = 3/2 + 8/3 = 9/6 + 16/6 = 25/6 = 4又1/6

第三篇：运算定律与简便运算
============================================================

七、五大运算定律

【加法交换律】
a+b = b+a。交换加数位置，和不变。
应用：37+56+63 = 37+63+56 = 100+56 = 156

【加法结合律】
(a+b)+c = a+(b+c)。先加哪两个数，和不变。
应用：125+98+75 = 125+75+98 = 200+98 = 298

【乘法交换律】
a×b = b×a。交换因数位置，积不变。
应用：25×37×4 = 25×4×37 = 100×37 = 3700

【乘法结合律】
(a×b)×c = a×(b×c)。先乘哪两个数，积不变。
应用：125×32×25 = 125×8×4×25 = (125×8)×(4×25) = 1000×100 = 100000

【乘法分配律】
(a+b)×c = a×c + b×c。最重要也最容易用错的定律。
正用：(40+4)×25 = 40×25+4×25 = 1000+100 = 1100
逆用：37×99+37 = 37×(99+1) = 37×100 = 3700
变式：(a-b)×c = a×c-b×c。如 (100-2)×35 = 3500-70 = 3430

八、运算性质

【减法性质】
a-b-c = a-(b+c)。连续减去两个数等于减去它们的和。
如 528-76-24 = 528-(76+24) = 528-100 = 428

【除法性质】
a÷b÷c = a÷(b×c)。连续除以两个数等于除以它们的积。
如 4800÷8÷25 = 4800÷(8×25) = 4800÷200 = 24

九、简便运算综合训练

【凑整十整百】
如 9999+999+99+9 = (10000-1)+(1000-1)+(100-1)+(10-1) = 11110-4 = 11106

【拆分法】
如 25×44 = 25×4×11 = 100×11 = 1100
如 125×56 = 125×8×7 = 1000×7 = 7000

【变形法】
如 78×101-78 = 78×(101-1) = 78×100 = 7800
如 999×222+333×334 = 333×3×222+333×334 = 333×(666+334) = 333×1000 = 333000

【易错提醒】
简便运算不能改变运算顺序！如 25×4÷25×4 ≠ 1，正确算法是 (25×4)÷(25×4) 或从左到右算 = 100÷25×4 = 4×4 = 16。

第四篇：数学思维方法
============================================================

十、画图思维

【线段图】
用线段表示数量关系，是小学最重要的数学思维工具。
适用题型：和差问题、和倍问题、差倍问题、分数应用题、行程问题。
画线段图步骤：确定单位1画一条线段→根据题意分段标注→找出对应关系。

【面积图】
用长方形面积表示乘法，帮助理解乘法分配律。
如 (a+b)×c = a×c+b×c：画一个大长方形分成两部分，面积之和等于总面积。

【集合图（韦恩图）】
用圆圈表示集合的重叠关系。解决"两个班都订阅的有多少人"等重叠问题。
如 A班订报纸30人，B班订报纸28人，两班共订了45人，两班都订的 = 30+28-45 = 13人。

十一、列举与枚举思维

【有序列举】
按一定顺序把所有可能情况列出来，不重复不遗漏。
如：用1、2、3三个数字组成不同的三位数，有几种？
先定百位：百位是1→123、132；百位是2→213、231；百位是3→312、321。共6种。

【列表法】
把条件列成表格，逐步排除或确定。适合鸡兔同笼、搭配问题、逻辑推理。

十二、逆向思维

【倒推法】
从结果出发倒推到已知条件。适合"已知最后结果，求原来是多少"的问题。
如：一个数加上5，乘以3，减去7，等于20，求这个数。
倒推：20+7=27，27÷3=9，9-5=4。这个数是4。

【逆运算】
加法的逆运算是减法，乘法的逆运算是除法。用逆运算可以验算。

十三、转化思维

【把新问题转化成旧问题】
如：分数除法→转化为分数乘法（除以一个数=乘它的倒数）
如：平行四边形面积→割补转化为长方形面积
如：圆柱体积→切拼转化为长方体体积

【把复杂问题转化成简单问题】
如：计算 1/2+1/4+1/8+1/16 → 画图发现结果 = 1-1/16 = 15/16

十四、分类讨论思维

【什么情况需要分类】
当问题有多种可能情况时，要分情况讨论，保证不重复不遗漏。
如：等腰三角形两边长分别是3和7，周长是多少？
情况一：腰是3，底是7→3+3=6<7，不能构成三角形（两边之和要大于第三边）。
情况二：腰是7，底是3→周长 = 7+7+3 = 17。

十五、对应思维

【找对应关系】
分数应用题中的"量"和"率"要对应。
如：全班40人，男生占3/5。男生人数 = 全班人数×3/5 = 40×3/5 = 24人。
这里"男生人数"对应"3/5"，"全班人数"对应"1"（单位1）。

第五篇：经典思维题型
============================================================

十六、找规律

【数列找规律】
观察相邻两项的差、倍数关系、奇偶变化。
如：2, 5, 10, 17, 26, …（差分别是3, 5, 7, 9, …递增2，下一个差是11，下一项是37）
如：1, 1, 2, 3, 5, 8, 13, …（斐波那契数列：前两项之和等于第三项，下一项是21）

【图形找规律】
观察图形的数量、位置、方向、颜色的变化规律。
如第1个图1个点，第2个图3个点，第3个图6个点，第4个图10个点（每次增加数递增1）。

十七、最值问题

【周长固定求最大面积】
周长一定时，长和宽越接近（越像正方形）面积越大。
如用20米栅栏围长方形（长宽取整数），面积最大是多少？
长+宽=10，当长=宽=5时（正方形），面积=25平方米最大。

【方案最优化】
沏茶问题：合理安排顺序，能同时做的事同时做。
如烧水8分钟、洗茶杯2分钟、找茶叶1分钟、泡茶1分钟。烧水的同时洗茶杯和找茶叶，共需8+1=9分钟。

十八、还原问题

【倒推还原】
已知最后结果，逐步倒推求出原始数据。
如：小明有一些弹珠，第一次给了小红一半多1个，第二次给了小华剩下的一半多1个，最后还剩1个。小明原来有多少个？
倒推：第二次给之前=(1+1)×2=4个，第一次给之前=(4+1)×2=10个。

十九、定义新运算

【理解新规则】
如规定 a※b = 3a-2b，求 5※4 和 4※5。
5※4 = 3×5-2×4 = 15-8 = 7
4※5 = 3×4-2×5 = 12-10 = 2
注意：新运算一般不满足交换律（5※4 ≠ 4※5）。

二十、巧求周长和面积

【割补法】
不规则图形通过切割、拼补变成规则图形。
如L形图形可以切成两个长方形或补成一个大长方形减去一个小长方形。

【平移法】
把图形的一部分平移到另一处，拼成规则图形。
如楼梯形图形平移后变成长方形。

【等积变形】
同底等高的三角形面积相等。平行线间的三角形面积不变。
如三角形ABC和三角形DBC共底BC，且A和D在同一条平行于BC的直线上，则两个三角形面积相等。

计算是数学的基石，思维是数学的翅膀。口算要天天练，速算技巧要灵活运用，解题方法要举一反三。做计算题要养成验算的好习惯，做思维题要养成画图分析的好习惯。坚持练习，计算越来越快，思维越来越灵活。
