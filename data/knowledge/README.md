# 小学知识库

系统会递归读取本目录下的 UTF-8 `.txt` 和 `.pdf` 文件。

文件名建议以学科开头，例如 `数学_分数专题.txt`。支持的学科由
`config/app.yml` 配置。修改、增加或删除文件后，下一次检索会根据
SHA-256 清单自动同步对应向量分片。
