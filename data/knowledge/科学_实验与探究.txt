小学科学实验与探究百科

本资料面向小学三至六年级，精选适合小学生操作的科学实验，涵盖物理、化学、生物三大领域。每个实验配原理讲解和安全提醒。动手做实验是学习科学最好的方式——看到现象、提出问题、找到答案。

============================================================
第一篇：力学实验
============================================================

一、摩擦力实验

【实验目的】研究什么因素影响摩擦力大小。
【材料】木块、弹簧测力计、毛巾、砂纸、不同重量的砝码。
【步骤】
1. 用弹簧测力计匀速拉动木块在桌面上滑动，记录拉力。
2. 在桌面上铺毛巾，重复实验，记录拉力。
3. 在桌面上铺砂纸，重复实验，记录拉力。
4. 在木块上加砝码增加重量，在桌面上拉动，记录拉力。
【现象】毛巾和砂纸上的拉力更大；木块越重拉力越大。
【结论】接触面越粗糙，摩擦力越大。物体越重，摩擦力越大。

二、浮力实验

【实验目的】探究物体沉浮的条件。
【材料】水盆、水、食盐、鸡蛋、各种小物件（硬币、塑料块、木块、铁钉）。
【步骤】
1. 把各种小物件放入水中，观察哪些沉哪些浮。
2. 把鸡蛋放入清水——鸡蛋沉底。
3. 逐渐往水中加盐搅拌——鸡蛋慢慢浮起来。
【原理】物体密度大于水则沉，小于水则浮。加盐增大水的密度，鸡蛋密度相对变小就浮了。死海就是盐水浓度极高，人可以浮在水面。

三、大气压实验

【实验一：纸片托水】
材料：玻璃杯、水、硬纸片。
步骤：杯中装满水，盖上纸片，快速翻转。纸片不掉落！
原理：大气压从下方托住纸片，比水的重力还大。

【实验二：吸盘】
材料：两个吸盘挂钩。
步骤：把两个吸盘对扣，挤出空气。两个人拉也拉不开！
原理：挤出空气后内部接近真空，外部大气压把两个吸盘紧紧压在一起。

第二篇：光学实验
============================================================

四、小孔成像

【材料】纸杯、保鲜膜、橡皮筋、蜡烛、针。
【步骤】
1. 纸杯底部用针戳一个小孔。
2. 杯口蒙上保鲜膜，用橡皮筋固定（当屏幕）。
3. 在暗室中，把小孔对准点燃的蜡烛。
4. 保鲜膜上出现蜡烛的像——倒立的！
【原理】光沿直线传播。蜡烛上方的光通过小孔射到下方，下方的光射到上方，形成倒立的像。

五、光的色散

【材料】一盆水、平面镜、白纸、阳光。
【步骤】
1. 把平面镜斜放入水盆中（一半在水下一半在水上）。
2. 让阳光照射到水下的镜面。
3. 反射的光投射到白纸上——出现彩虹色带！
【原理】白光由红橙黄绿蓝靛紫七种颜色的光混合而成。水像三棱镜一样把不同颜色的光按不同角度折射分开。

六、自制彩虹

【材料】喷雾瓶、晴天阳光。
【步骤】背对太阳，用喷雾瓶向空中喷出水雾。
【现象】水雾中出现一道小彩虹！
【原理】每个小水滴都像一个小三棱镜，把阳光折射和反射后分解成七色光。

第三篇：电与磁实验
============================================================

七、自制电磁铁

【材料】大铁钉、漆包线（绝缘导线）、电池、小铁钉若干。
【步骤】
1. 把漆包线紧密绕在大铁钉上（绕50-100圈）。
2. 导线两端分别接在电池正负极上。
3. 铁钉就能吸起小铁钉了！
4. 断开电路，铁钉不再吸铁。
【原理】通电导线产生磁场，铁芯被磁化后磁性大大增强。电磁铁的磁性可控（通电有、断电无）、可调（改变圈数或电流）。

八、简易电路

【材料】电池、小灯泡、导线、开关（可以用铝箔纸自制）。
【步骤】
1. 用导线把电池、开关、灯泡串联起来。
2. 闭合开关——灯泡亮了！
3. 断开开关——灯泡灭了。
【安全提醒】只能用干电池做实验，绝对不能碰家用220V交流电！

九、静电实验

【材料】塑料尺、碎纸屑、毛料布。
【步骤】
1. 把塑料尺在毛料布上摩擦20次。
2. 把尺子靠近碎纸屑——纸屑被吸起来了！
3. 把摩擦过的尺子靠近细细的水流——水流被吸引弯曲。
【原理】摩擦使尺子带电（静电）。带电体能吸引轻小物体。

第四篇：化学变化实验
============================================================

十、小苏打与白醋反应

【材料】小苏打、白醋、透明杯子、气球。
【步骤】
1. 杯中倒入白醋。
2. 把小苏打装进气球。
3. 把气球口套在杯口，让小苏打倒入醋中。
4. 大量气泡产生，气球被吹起来了！
【原理】小苏打（碳酸氢钠）+ 白醋（醋酸）→ 醋酸钠 + 水 + 二氧化碳气体。产生的二氧化碳把气球吹起来。这是化学变化——产生了新物质。

十一、紫甘蓝指示剂

【材料】紫甘蓝、热水、白醋、小苏打水、柠檬汁、肥皂水。
【步骤】
1. 把紫甘蓝叶切碎，用热水浸泡10分钟，得到紫色液体。
2. 分别倒入不同杯子中。
3. 加白醋→变红色（酸性）。加柠檬汁→变粉色。
4. 加小苏打水→变蓝色（碱性）。加肥皂水→变绿色。
【原理】紫甘蓝中含花青素，遇酸变红、遇碱变蓝绿，是天然的酸碱指示剂。

十二、牛奶动画

【材料】全脂牛奶、食用色素、洗洁精、棉签、盘子。
【步骤】
1. 盘中倒入牛奶。
2. 在牛奶中央滴几种不同颜色的食用色素。
3. 用棉签蘸洗洁精，轻轻触碰牛奶表面。
4. 色素瞬间四散开来，形成美丽的花纹！
【原理】洗洁精（表面活性剂）破坏了牛奶表面的张力，同时与牛奶中的脂肪发生作用，带动色素流动。

第五篇：生物实验
============================================================

十三、种子萌发观察

【材料】绿豆、透明杯子、纸巾、水。
【步骤】
1. 把纸巾卷成筒状塞入杯壁内侧。
2. 在纸巾和杯壁之间放几颗绿豆。
3. 往杯中加少量水（保持纸巾湿润但不要淹没种子）。
4. 每天观察并记录。
【观察日记模板】
第1天：绿豆吸水膨胀，种皮变软。
第3天：种皮裂开，胚根先长出（向下生长）。
第5天：胚根长成白色根，胚芽开始长出（向上生长）。
第7天：长出绿色子叶，开始光合作用。
第10天：真叶长出，幼苗独立生长。

十四、光合作用验证

【材料】天竺葵、黑纸、回形针、酒精、碘液。
【步骤】
1. 天竺葵放在暗处一昼夜（消耗原有淀粉）。
2. 用黑纸遮住一片叶子的一部分，用回形针固定。
3. 放在阳光下照射4小时。
4. 摘下叶子，放入酒精中水浴加热脱色。
5. 滴加碘液。
【现象】遮光部分不变色（无淀粉），曝光部分变蓝紫色（有淀粉）。
【结论】光合作用需要光，产物中有淀粉。

十五、霉菌生长观察

【材料】面包片、密封袋、水。
【步骤】
1. 两片面包，一片干燥，一片喷水弄湿。
2. 分别放入密封袋，放在温暖处。
3. 每天观察记录。
【现象】湿面包2-3天后长出绿色/黑色霉斑。干燥面包变化很小。
【结论】霉菌生长需要水分和温暖环境。防止食物发霉要保持干燥和低温。

第六篇：实验记录与报告
============================================================

十六、实验记录规范

【记录要素】
实验名称、实验日期、实验目的、实验材料、实验步骤、实验现象（文字+图画）、实验结论、我的疑问。

【注意事项】
如实记录——即使结果和猜想不同也要如实记。
用数据说话——能测量的要测量并记录数据。
画图辅助——用简笔画记录实验装置和现象。
重复实验——做3次取平均值，减少误差。

安全是第一原则！所有实验都要在老师或家长指导下进行。不品尝任何实验材料，不用嘴吹灭酒精灯，实验后洗手。安全第一，探索第二。
