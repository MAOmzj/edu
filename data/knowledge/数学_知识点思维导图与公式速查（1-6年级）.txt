小学数学知识点思维导图与公式速查（1-6年级）

本资料用思维导图的方式整理小学数学核心知识点，按年级分层，方便学生梳理知识框架、考前快速复习。每个知识点配核心公式和易错提醒。

============================================================
一年级知识框架
============================================================

【数与计算】
├─ 1-10的认识（数数、比大小、第几）
├─ 1-5加减法（理解加法和减法含义）
├─ 6-10加减法（凑十法、数的组成）
├─ 11-20各数（十位和个位）
└─ 20以内进位加法和退位减法（凑十法、破十法）

【图形与位置】
├─ 立体图形：长方体、正方体、圆柱、球
└─ 位置：上下、前后、左右

【认识钟表】
└─ 整时和半时

易错提醒：
- "几"和"第几"要分清（基数vs序数）
- 左右的相对性（面对面时左右相反）

============================================================
二年级知识框架
============================================================

【数与计算】
├─ 100以内加减法（进位加、退位减、竖式）
├─ 表内乘法（1-9乘法口诀）
├─ 表内除法（平均分、包含除）
├─ 混合运算（先乘除后加减）
└─ 有余数的除法（余数<除数）

【量与计量】
├─ 长度：厘米、米（1米=100厘米）
├─ 毫米、分米、千米（1千米=1000米）
└─ 吨（1吨=1000千克）

【图形】
└─ 平面图形：长方形、正方形、三角形、圆、平行四边形

易错提醒：
- 竖式计算忘记进位"1"或退位点"·"
- 运算顺序错误（如5+3×2=11，不是16）
- 余数≥除数说明商偏小

============================================================
三年级知识框架
============================================================

【数与计算】
├─ 万以内加减法（三位数竖式）
├─ 多位数乘一位数
├─ 两位数乘两位数
├─ 除数是一位数的除法
├─ 分数初步认识
└─ 小数的意义和性质

【量与计量】
├─ 时间：时、分、秒（1时=60分，1分=60秒）
└─ 面积单位：平方厘米、平方分米、平方米

【图形】
├─ 周长：长方形=(长+宽)×2，正方形=边长×4
├─ 面积：长方形=长×宽，正方形=边长×边长
└─ 面积vs周长（周长是边线长度，面积是面的大小）

易错提醒：
- 时间进率是60，不是100
- 面积单位进率是100，不是10
- 周长和面积公式不能混淆

============================================================
四年级知识框架
============================================================

【数与计算】
├─ 大数的认识（万、十万、百万、千万、亿）
├─ 三位数乘两位数
├─ 除数是两位数的除法
├─ 运算定律（交换律、结合律、分配律）
└─ 小数的加减法

【图形】
├─ 角的度量（用量角器）
├─ 三角形（特性、分类、内角和=180°）
├─ 平行四边形和梯形
└─ 图形的运动（轴对称、平移）

【统计】
└─ 平均数=总和÷个数

易错提醒：
- 读数时每级末尾的0不读，中间的0只读一个
- 试商偏大或偏小需要调整
- 小数点移动方向搞反
- 小数加减法忘记对齐小数点

============================================================
五年级知识框架
============================================================

【数与计算】
├─ 小数乘除法
├─ 简易方程（用字母表示数、等式性质）
├─ 分数的意义和性质（真分数、假分数、带分数）
├─ 分数加减法（同分母、异分母）
└─ 因数与倍数（2/3/5倍数特征、质数合数）

【图形】
├─ 多边形面积
│  ├─ 平行四边形=底×高
│  ├─ 三角形=底×高÷2 ⚠️
│  └─ 梯形=(上底+下底)×高÷2 ⚠️
├─ 长方体和正方体
│  ├─ 表面积=(长×宽+长×高+宽×高)×2
│  └─ 体积=长×宽×高
└─ 最大公因数和最小公倍数（短除法）

【统计】
└─ 折线统计图（看变化趋势）

易错提醒：
- 小数乘法小数位数数错
- 小数除法被除数和除数忘同扩
- 三角形和梯形面积忘÷2
- 实际问题算几个面（如无盖鱼缸5个面）

============================================================
六年级知识框架
============================================================

【数与计算】
├─ 分数乘除法
├─ 百分数（折扣、成数、税率、利率）
├─ 比（化简比、求比值）
├─ 负数
└─ 比例（正比例、反比例）

【图形】
├─ 圆
│  ├─ 周长C=πd=2πr
│  └─ 面积S=πr² ⚠️ r²是r×r不是r×2
├─ 圆柱
│  ├─ 侧面积=底面周长×高=2πrh
│  └─ 体积=底面积×高=πr²h
├─ 圆锥
│  └─ 体积=1/3×底面积×高=1/3πr²h ⚠️
└─ 比例尺=图上距离:实际距离

【统计】
└─ 扇形统计图（各扇形百分比之和=100%）

易错提醒：
- 分数除法只变除号没变倒数
- 百分数不带单位
- 圆面积r²算错
- 圆锥体积忘×1/3
- 比例尺计算忘统一单位

核心公式速查表
============================================================

【运算定律】
加法交换律：a+b=b+a
加法结合律：(a+b)+c=a+(b+c)
乘法交换律：a×b=b×a
乘法结合律：(a×b)×c=a×(b×c)
乘法分配律：(a+b)×c=a×c+b×c
减法性质：a-b-c=a-(b+c)
除法性质：a÷b÷c=a÷(b×c)

【图形公式】
长方形周长=(长+宽)×2
正方形周长=边长×4
长方形面积=长×宽
正方形面积=边长×边长
平行四边形面积=底×高
三角形面积=底×高÷2
梯形面积=(上底+下底)×高÷2
圆周长C=2πr=πd
圆面积S=πr²
长方体表面积=(ab+ah+bh)×2
长方体体积=长×宽×高=Sh
正方体表面积=6a²
正方体体积=a³
圆柱侧面积=2πrh
圆柱体积=πr²h=Sh
圆锥体积=1/3πr²h

【数量关系】
路程=速度×时间
总价=单价×数量
工作总量=工作效率×工作时间
利息=本金×利率×存期
浓度=溶质÷溶液×100%
