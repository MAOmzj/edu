# 小学科学实验与探究手册

## 第一篇：植物实验

### 实验1：观察种子发芽

**实验目的**：观察种子发芽的过程，了解种子萌发的条件。

**实验材料**：
- 绿豆或黄豆10粒
- 透明塑料杯2个
- 纸巾若干
- 水

**实验步骤**：
1. 将纸巾浸湿，放入塑料杯中
2. 在每个杯子中放入5粒绿豆
3. 1号杯放在阳光下，每天喷水保持湿润
4. 2号杯放在黑暗处，每天喷水保持湿润
5. 每天观察并记录

**观察记录表**：
| 天数 | 1号杯（阳光下） | 2号杯（黑暗中） |
|------|----------------|----------------|
| 第1天 |                |                |
| 第2天 |                |                |
| 第3天 |                |                |
| 第4天 |                |                |
| 第5天 |                |                |

**实验结论**：
- 种子萌发需要水分、空气和适宜的温度
- 光照不是种子萌发的必要条件
- 种子萌发时先长出根，再长出芽

### 实验2：探究植物的向光性

**实验目的**：观察植物是否具有向光性。

**实验材料**：
- 纸盒1个（一侧开孔）
- 绿豆苗1株
- 水

**实验步骤**：
1. 将绿豆苗种在花盆中
2. 用纸盒罩住绿豆苗，开孔朝向一侧
3. 每天观察豆苗的生长方向
4. 记录观察结果

**观察记录**：
| 天数 | 豆苗生长方向 | 与开孔的关系 |
|------|-------------|-------------|
| 第1天 |             |             |
| 第3天 |             |             |
| 第5天 |             |             |
| 第7天 |             |             |

**实验结论**：
植物具有向光性，会向着光源方向生长。

### 实验3：观察叶片的结构

**实验目的**：观察叶片的结构，了解叶片的组成。

**实验材料**：
- 新鲜叶片（如菠菜叶）
- 显微镜
- 载玻片、盖玻片
- 镊子
- 水

**实验步骤**：
1. 用镊子撕取叶片的下表皮
2. 将表皮放在载玻片上，滴一滴水
3. 盖上盖玻片
4. 用显微镜观察
5. 绘制观察到的结构

**观察结果**：
- 可以看到气孔
- 气孔由两个保卫细胞围成
- 气孔是植物进行气体交换的通道

### 实验4：探究光合作用的条件

**实验目的**：验证光合作用需要光和叶绿体。

**实验材料**：
- 天竺葵一盆
- 黑纸或铝箔
- 回形针
- 酒精
- 碘液
- 烧杯
- 三角架
- 酒精灯

**实验步骤**：
1. 将天竺葵放在黑暗处一昼夜（消耗原有淀粉）
2. 用黑纸遮住一片叶子的一部分，用回形针固定
3. 将植物放在阳光下照射4小时
4. 摘下遮光的叶子，去掉黑纸
5. 将叶片放入酒精中水浴加热（脱色）
6. 用清水漂洗叶片
7. 滴加碘液，观察颜色变化

**实验结果**：
- 遮光部分：不变蓝（无淀粉）
- 曝光部分：变蓝（有淀粉）

**实验结论**：
光合作用需要光，产物中有淀粉。

### 实验7：探究蚯蚓的生活环境

**实验目的**：探究蚯蚓喜欢生活在什么样的环境中。

**实验材料**：
- 蚯蚓10条
- 塑料盒1个
- 干土
- 湿土
- 黑纸
- 透明塑料膜

**实验步骤**：
1. 在塑料盒中一边放干土，一边放湿土
2. 将蚯蚓放在中间
3. 观察蚯蚓的选择
4. 在塑料盒一半盖上黑纸，一半用透明膜
5. 观察蚯蚓对光照的选择
6. 记录观察结果

**实验结果**：
| 实验 | 蚯蚓的选择 |
|------|-----------|
| 干土vs湿土 | 选择湿土 |
| 黑暗vs明亮 | 选择黑暗 |

**实验结论**：
蚯蚓喜欢生活在潮湿、黑暗的环境中。

## 第三篇：物理实验

### 实验8：探究声音的产生

**实验目的**：验证声音是由物体振动产生的。

**实验材料**：
- 鼓
- 豆子或沙子
- 音叉
- 水槽

**实验步骤**：
1. 在鼓面上撒一些豆子
2. 敲击鼓面，观察豆子的运动
3. 敲击音叉，将音叉放入水中，观察水面变化
4. 记录观察结果

**实验现象**：
- 敲鼓时，豆子跳动
- 音叉放入水中，水面溅起水花

**实验结论**：
声音是由物体振动产生的。振动停止，声音消失。

### 实验9：探究光的直线传播

**实验目的**：验证光沿直线传播。

**实验材料**：
- 手电筒
- 三张带小孔的纸板
- 支架

**实验步骤**：
1. 将三张带孔纸板排成一行，孔在一条直线上
2. 用手电筒照射，观察光是否能通过所有孔
3. 移动一张纸板，使孔不在一条直线上
4. 再次照射，观察现象
5. 记录实验结果

**实验现象**：
- 孔在一条直线上：光能通过所有孔
- 孔不在一条直线上：光不能通过

**实验结论**：
光沿直线传播。

### 实验10：探究影子的形成

**实验目的**：探究影子形成的条件和特点。

**实验材料**：
- 手电筒
- 各种物体（玩具、书本等）
- 白色屏幕

**实验步骤**：
1. 打开手电筒，照射白色屏幕
2. 在手电筒和屏幕之间放置物体，观察影子
3. 改变物体与手电筒的距离，观察影子大小变化
4. 改变物体与屏幕的距离，观察影子大小变化
5. 记录观察结果

**实验结果**：
| 条件 | 影子特点 |
|------|---------|
| 物体靠近光源 | 影子变大 |
| 物体远离光源 | 影子变小 |
| 物体靠近屏幕 | 影子变小 |
| 物体远离屏幕 | 影子变大 |

**实验结论**：
- 影子形成需要光源和不透明物体
- 影子的大小与物体和光源、屏幕的距离有关

### 实验11：探究浮力

**实验目的**：探究物体沉浮的条件。

**实验材料**：
- 水槽
- 各种物体（木块、铁块、塑料块、橡皮泥等）
- 水
- 盐

**实验步骤**：
1. 将各种物体放入水中，观察沉浮情况
2. 记录哪些物体沉，哪些物体浮
3. 将橡皮泥做成船形，观察沉浮
4. 在水中加盐，观察鸡蛋的沉浮变化
5. 记录实验结果

**实验结果**：
| 物体 | 沉浮情况 | 原因 |
|------|---------|------|
| 木块 | 浮 | 密度小于水 |
| 铁块 | 沉 | 密度大于水 |
| 塑料块 | 浮 | 密度小于水 |
| 橡皮泥（球形） | 沉 | 密度大于水 |
| 橡皮泥（船形） | 浮 | 排开水的体积增大 |
| 鸡蛋（清水） | 沉 | 密度大于水 |
| 鸡蛋（盐水） | 浮 | 盐水密度大于鸡蛋 |

**实验结论**：
- 物体的沉浮与物体的密度有关
- 改变物体的形状可以改变沉浮状态
- 改变液体的密度可以改变物体的沉浮

### 实验12：探究热传递

**实验目的**：探究热的三种传递方式。

**实验材料**：
- 金属棒
- 蜡烛
- 火柴
- 热水
- 冷水
- 两个烧杯

**实验步骤**：
**热传导实验**：
1. 在金属棒上等距离粘上火柴
2. 用蜡烛加热金属棒的一端
3. 观察火柴掉落的顺序

**热对流实验**：
1. 在烧杯中装入冷水
2. 在水中放入一些茶叶
3. 加热烧杯底部
4. 观察茶叶的运动

**热辐射实验**：
1. 点燃蜡烛
2. 将手放在蜡烛侧面（不接触火焰）
3. 感受热量

**实验结果**：
- 热传导：火柴从靠近火焰的一端开始掉落
- 热对流：茶叶随水流上下运动
- 热辐射：手能感受到蜡烛的热量

**实验结论**：
- 热传导：热沿物体从高温传到低温
- 热对流：液体或气体流动传热
- 热辐射：热以射线形式传播，不需要介质

## 第四篇：化学实验

### 实验13：小苏打与白醋反应

**实验目的**：观察小苏打与白醋反应产生的现象。

**实验材料**：
- 小苏打
- 白醋
- 透明杯子
- 气球

**实验步骤**：
1. 在杯中倒入白醋
2. 将小苏打装入气球
3. 将气球口套在杯口
4. 将小苏打倒入白醋中
5. 观察现象

**实验现象**：
- 产生大量气泡
- 气球被吹起

**实验结论**：
小苏打与白醋反应产生二氧化碳气体。

### 实验14：自制酸碱指示剂

**实验目的**：用紫甘蓝制作酸碱指示剂。

**实验材料**：
- 紫甘蓝
- 热水
- 滤网
- 各种液体（白醋、苏打水、柠檬汁、肥皂水等）
- 透明杯子

**实验步骤**：
1. 将紫甘蓝切碎
2. 用热水浸泡10分钟
3. 用滤网过滤，得到紫色液体
4. 将紫色液体分别倒入不同杯子
5. 分别加入不同的液体
6. 观察颜色变化

**实验结果**：
| 加入液体 | 颜色变化 | 酸碱性 |
|---------|---------|--------|
| 白醋 | 变红 | 酸性 |
| 柠檬汁 | 变粉 | 酸性 |
| 苏打水 | 变蓝 | 碱性 |
| 肥皂水 | 变绿 | 碱性 |

**实验结论**：
紫甘蓝汁可以作为酸碱指示剂，遇酸变红，遇碱变蓝绿。

## 第五篇：地球与宇宙实验

### 实验16：模拟昼夜交替

**实验目的**：理解昼夜交替的原因。

**实验材料**：
- 地球仪
- 手电筒
- 小贴纸

**实验步骤**：
1. 在地球仪上贴上小贴纸，标记自己的位置
2. 用手电筒代表太阳，照射地球仪
3. 缓慢转动地球仪
4. 观察贴纸位置的光照变化
5. 记录观察结果

**实验现象**：
- 贴纸面向手电筒时：白天
- 贴纸背向手电筒时：黑夜
- 地球仪转动一周：经历一次昼夜交替

**实验结论**：
地球自转产生昼夜交替，自转一周约24小时。

### 实验17：模拟四季变化

**实验目的**：理解四季变化的原因。

**实验材料**：
- 地球仪
- 手电筒
- 倾斜支架

**实验步骤**：
1. 将地球仪倾斜23.5度（模拟地轴倾斜）
2. 用手电筒代表太阳
3. 让地球仪绕手电筒转动（公转）
4. 观察不同位置时，南北半球的光照情况
5. 记录观察结果

**实验现象**：
- 当地球在某一位置时：北半球光照多，是夏季；南半球光照少，是冬季
- 当地球转到对面位置时：情况相反

**实验结论**：
地球公转和地轴倾斜共同导致四季变化。

## 实验安全注意事项

### 一般安全规则
1. 实验前认真听老师讲解
2. 按照实验步骤操作
3. 不随意触摸实验器材
4. 实验中保持安静
5. 实验后整理器材

### 特殊安全事项
1. **使用酒精灯**：
   - 用火柴点燃，不能用另一个酒精灯点燃
   - 用灯帽盖灭，不能用嘴吹灭
   - 不要碰触酒精灯火焰

2. **使用化学药品**：
   - 不能品尝任何化学药品
   - 不能直接闻药品气味
   - 用药匙取用药品
   - 废液倒入指定容器

3. **使用玻璃器皿**：
   - 轻拿轻放
   - 破碎玻璃不能用手捡
   - 加热时注意均匀受热

4. **使用电器**：
   - 手要干燥
   - 不能私自拆卸
   - 发现异常立即断电
