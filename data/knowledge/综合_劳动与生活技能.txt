小学综合劳动与生活技能百科

本资料面向小学二至六年级，系统整理日常生活必备技能——整理收纳、烹饪基础、家务劳动、手工缝纫、安全操作等。劳动创造美好生活，生活技能是人生最基本的功课。学会照顾自己，才能独立、自信地成长。

============================================================
第一篇：整理收纳
============================================================

一、整理书包

【每天放学前】
1. 把明天需要的课本、作业本、文具装进书包。
2. 不需要的东西拿出来（今天的课本、已经交了的作业回执等）。
3. 课本按大小排列（大书在后、小书在前）。
4. 文具放在文具盒里，铅笔削好，橡皮准备好。
5. 检查有没有要家长签字的材料。

【每周大整理】
周末清理书包：倒出碎纸屑、用过的纸巾、不需要的纸。
检查文具：铅笔是否够用、橡皮有没有丢、尺子还在不在。

二、整理书桌

【整理原则】
常用的东西放在手边，不常用的放在抽屉里。
桌面只留正在使用的物品。

【整理步骤】
1. 把桌上所有东西拿下来。
2. 分类：学习用品、课外书、杂物、垃圾。
3. 擦干净桌面。
4. 学习用品放回桌面（笔筒、书架）。
5. 课外书排在书架上（按大小或类别）。
6. 杂物收纳进抽屉。
7. 垃圾扔掉。

三、整理房间

【整理四步法】
1. 归位：把东西放回它应该在的地方。
2. 分类：衣物、书籍、玩具、文具、杂物。
3. 清洁：扫地、擦桌子、整理床铺。
4. 维持：用完东西随手放回原处。

【叠衣服】
T恤：铺平→两袖向内折→对折→叠成小块。
裤子：对折→再对折→叠成方块。
袜子：两只叠在一起卷成球。

第二篇：烹饪基础
============================================================

四、厨房安全

【安全守则】
必须在家长指导下使用刀具和灶具。
不把手伸进运转中的搅拌机/榨汁机。
热锅热油不能溅入水滴（会炸溅伤人）。
使用刀具时注意力集中，不边切菜边聊天。
用完灶具要关火关气。

【刀具使用】
切菜时手指弯曲扣住食材（"猫爪手"），刀贴着指关节切。
切硬物（如南瓜）要固定好食材，不要悬空切。
刀具用完擦干净放回刀架，不要泡在水槽里（看不见会割伤手）。

五、简单烹饪

【煮面条】
1. 锅中加足够的水，大火烧开。
2. 水开后放入面条，用筷子搅散防止粘连。
3. 再次煮开后调中火，煮3-5分钟（看包装说明）。
4. 用筷子夹一根尝尝——没有硬芯就熟了。
5. 用漏勺捞出，过冷水（做凉面）或直接拌酱。

【煮鸡蛋】
1. 鸡蛋放入锅中，加冷水没过鸡蛋。
2. 大火烧开后转中火。
3. 煮3分钟（溏心蛋）、5分钟（半熟）、8分钟（全熟）。
4. 捞出放入冷水中（好剥壳）。

【做简单沙拉】
1. 蔬菜洗净（生菜、黄瓜、西红柿）。
2. 黄瓜切片，西红柿切块，生菜撕小块。
3. 放入碗中，加沙拉酱拌匀。

【炒鸡蛋】
1. 鸡蛋打入碗中，加少许盐，用筷子打散。
2. 锅中放少量油，中火加热。
3. 油热后倒入蛋液，等底部凝固后用铲子翻动。
4. 炒到全部凝固就可以出锅（不要炒太久会变老）。

六、水果处理

【洗水果】
流水冲洗30秒以上。需要的话用软刷轻刷表面。
草莓、葡萄等娇嫩水果用流水轻轻冲，不要用力搓。

【切水果】
苹果：洗净→竖切四瓣→去核→切小块。
香蕉：剥皮→切片或切段。
西瓜：切半→切块→用刀沿皮切下果肉。
⚠️ 使用刀具时一定让家长在旁边。

第三篇：家务劳动
============================================================

七、扫地和拖地

【扫地】
1. 先收拾地上的杂物（玩具、书本等放回原处）。
2. 从房间最里面开始扫，往门口方向扫。
3. 扫到一个角落集中，用簸箕收起倒进垃圾桶。
4. 注意扫角落和家具底下。

【拖地】
1. 先扫干净再拖。
2. 拖把拧到半干（不要太湿）。
3. 从房间最里面往外拖，边拖边后退（不踩刚拖过的地方）。
4. 拖把脏了在水桶里清洗拧干再拖。

八、洗碗

【步骤】
1. 先把碗中残余食物倒进垃圾桶。
2. 在海绵/洗碗布上挤洗洁精。
3. 先洗不太油的（杯子、饭碗），再洗很油的（炒菜锅、油碗）。
4. 里外都洗到，注意碗沿和碗底。
5. 用清水冲干净（没有泡沫为止）。
6. 放在沥水架上晾干，或擦干后放入碗柜。

九、洗衣服（手洗小件）

【步骤】
1. 盆中接温水，放入适量洗衣液。
2. 把衣服浸入水中浸泡5分钟。
3. 重点搓洗脏的地方（领口、袖口）。
4. 换清水漂洗2-3次，直到水清。
5. 拧干（不要用力拧变形），晾在衣架上。

十、叠被子

【步骤】
1. 起床后先把被子铺平。
2. 两边向中间折（折成长条）。
3. 两头向中间折（或从一头卷到另一头）。
4. 放好枕头。
不需要叠得像军训那么标准——整洁就行。

第四篇：手工与缝纫
============================================================

十一、基本针线活

【穿针引线】
1. 剪一段约40厘米的线。
2. 把线头捻尖（或用唾液润湿），穿过针眼。
3. 拉出一段后打结（绕两圈拉紧）。

【基本缝法】
平针缝：最基本的缝法。针从布下面穿上来，再穿下去，一针一针直线缝。用于缝合两块布。
回针缝：更牢固。每缝一针都要退回上一针的位置再往前走。用于需要结实的地方。
收口缝（藏针缝）：把线藏在布料内部，从外面看不到线迹。用于封口。

【缝扣子】
1. 在扣子应该在的位置做标记。
2. 从布下面穿上来，把扣子放好。
3. 针穿过扣子的一个孔再从另一个孔穿下去，重复4-5次。
4. 最后把针穿到布的背面打2-3个结，剪断线。

十二、简单手工

【折纸】
纸飞机：最经典的折纸。对折→折两个角→再对折→折翅膀。
纸船：对折→折两个角→打开底部撑成立体。
千纸鹤：需要更复杂的折叠步骤。

【剪纸】
对称剪纸：把纸对折2-3次，在折好的纸上画半个图案，沿线剪开，展开得到对称图案。
团花：正方形纸对折3次成三角形，在边缘剪出花纹，展开得到圆形团花。

第五篇：生活小窍门
============================================================

十三、生活常识

【去除污渍】
油渍：用洗洁精涂抹搓洗。
墨渍：用酒精或牙膏搓洗。
果汁渍：用白醋+水浸泡后清洗。
血渍：冷水浸泡（不要用热水！热水会让血渍凝固）。

【保存食物】
面包放冷冻室比放冷藏室更保鲜（冷藏反而加速老化）。
香蕉用保鲜膜包住蒂部可以延长保鲜期。
鸡蛋大头朝上放更保鲜。
苹果会加速其他水果成熟（释放乙烯），不要和其他水果放一起。

【节约能源】
离开房间随手关灯。
空调温度夏天26℃冬天20℃。
电视电脑不用时关机不拔插头也会耗电（待机功耗）。
洗手打肥皂时关水龙头。

十四、应急处理

【停电】
保持冷静。打开手机手电筒照明。
不要碰电器开关（来电时可能突然启动）。
冰箱不要频繁打开（保持低温）。
告诉家长。

【水管漏水】
先找到总阀门关掉（通常是水表旁边的阀门）。
告诉家长或物业来修。
用桶接住漏水，防止泡坏家具。

【迷路】
待在原地不要乱走（家长发现你不见会沿路找你）。
找穿制服的工作人员（警察、保安、商店店员）求助。
记住家长电话和家庭住址。
不要跟陌生人走。

生活技能看似简单，却是独立生活的基础。每学会一项新技能——叠衣服、煮面条、缝扣子——你就离"能照顾自己"更近了一步。不要等"长大了再学"——现在就开始，边学边做，你会越来越能干。
